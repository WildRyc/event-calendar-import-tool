# event-calendar-import-tool
Taking spreadsheet data and converting it so we can export a csv, which can be imported into The Events Calendar.


# Restrictions
The Events Calendar needs an exact match for Organizer and Venue names. If they do not exactly match, they will not import.

For example:

"Sword and Board" is not the same as "The Sword and Board" or "The Sword & Board"

Default to using exactly the names as they appear in the WPN WOTC Store Master List.
